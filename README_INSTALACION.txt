INSTALACION RAPIDA

1. Instala XAMPP.
2. Inicia Apache y MySQL.
3. Copia estos archivos dentro de C:\xampp\htdocs\web\
4. Entra a http://localhost/phpmyadmin
5. Pega y ejecuta el archivo database.sql en la pestana SQL.
6. Abre http://localhost/web/index.php
7. Login de prueba:
   correo: admin@quintadalam.com
   contrasena: Admin12345

IMPORTANTE:
- Si tu carpeta no se llama web, cambia /web/login.php dentro de auth.php.
- Conserva tu styles.css original en la misma carpeta.
- Ya se cumple: conexion BD, productos/servicios en BD, usuarios CRUD, roles, password_hash, sesiones, AJAX, formularios y commits.
